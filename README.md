# 肩内外旋計測（PWA） v2.0.0

肘頭と尺骨に貼った色マーカーを真下から撮影し、肩関節内外旋の角度・角速度・回数を計測するアプリ。
データは端末内だけに保存し、外部には送信しない。インストール後はオフラインで動く。

## 画面
- ① 基本情報：ID番号・回数・性別・年齢・測定側・条件・メモ
- ② 計測：リアルタイム計測／撮影のみ／動画を解析
- ③ 記録：計測結果（CSV書き出し）と撮影した動画（解析・端末に保存）
- 設定：色の許容幅・平滑化など

ファイル名は「ID＋ID番号_回数_性別（男M／女W）」。例：ID12_3_M.csv、ID12_3_M.mp4
CSVの先頭に基本情報が入る。

## 公開（GitHub Pages）
1. リポジトリにこのフォルダのファイルをそのままアップロード
2. Settings → Pages → Branch を main / (root) にして保存
3. https://<ユーザー名>.github.io/<リポジトリ名>/ をスマホで開き、ホーム画面に追加

## 更新するとき
sw.js の VERSION と index.html の APP_VERSION を変えてアップロードする。記録は消えない。

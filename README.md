# 肩内外旋計測（PWA）

肘頭と尺骨に貼った色マーカーを真下から撮影し、肩関節内外旋の角度・角速度・回数を計測するアプリです。
データは端末内（IndexedDB）だけに保存し、外部には送信しません。インストール後はオフラインで動きます。

## 公開（GitHub Pages）
1. GitHub で新しいリポジトリを作る（例：shoulder-rot-app）
2. このフォルダのファイル（index.html, manifest.webmanifest, sw.js, icon-*.png）をそのままアップロード
3. Settings → Pages → Branch を main / (root) にして保存
4. 数分後に https://<ユーザー名>.github.io/shoulder-rot-app/ で開ける

## 端末へのインストール
- iPhone/iPad：Safari で開く → 共有ボタン →「ホーム画面に追加」
- Android：Chrome で開く → メニュー →「アプリをインストール」（または「ホーム画面に追加」）

## 更新するとき
index.html を直したら、sw.js の VERSION と index.html の APP_VERSION を変えてアップロードする。
アプリを1回開き直すと新しい版に切り替わる（記録は消えない）。

## 速さテスト
「速さテスト」で、0°→外旋の目標（初期45°）→戻りの判定（初期0°）までを1回として、
「10回にかかる時間」または「10秒間の回数」と、1回ごとの時間・最大外旋角度・角速度を記録する。

## 注意
- 記録はアプリ（ブラウザ）の中に保存される。アプリを削除すると記録も消えるので、必要なものはCSVで書き出す。
- iPhone では CSV 保存時に共有画面が出るので「"ファイル"に保存」を選ぶ。
